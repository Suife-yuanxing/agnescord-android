# 林念念（AgnesCord）UI 重构完整实施方案

> 创建日期：2026-06-27
> 来源：UI 重构设计方向 + 验收标准 + 设计决策合并

---

## 一、总体方向

- **重构范围**：保留品牌核心（#F472B6 + 猫娘IP），视觉语言全面换代
- **IP 角色**：情感陪伴 + 全面角色化，Agnes 心情系统贯穿全旅程
- **对标产品**：聊天体验对标微信标准
- **交付方式**：先逐页改造确认视觉（独立HTML），再组装为SPA

---

## 二、视觉设计体系

### 2.1 视觉范式：统一 Soft Glass + 情感浓度梯度

- 全局基础：Soft Glass（进化版玻璃拟态），从 Claymorphism 进化为"轻盈水雾"
- 通过 `data-emotion` 属性控制 5 档情感浓度（5→1）：

| 档位 | 适用页面 | 视觉表现 |
|------|---------|---------|
| 5/5 | 启动页/聊天页 | 高透明度卡片+blur12px+2-3彩色光球+猫娘常驻+花瓣+20-22px圆角+品牌色投影 |
| 4/5 | 首页仪表盘/我的 | 中等装饰浓度 |
| 3/5 | Bot管理/创建向导/通知 | 适度装饰 |
| 2/5 | 设置/编辑个人资料 | 极简装饰 |
| 1/5 | 数据面板/管理员/API Key | 高不透明度卡片+无blur+无光球+纯灰阴影+12-14px圆角 |

- 所有页面共享同一套CSS变量，零割裂感

### 2.2 色彩系统

- 主色：#F472B6（保留不变）
- 次色：#ADD8E6（婴儿蓝）、强调色：#C4B5FD（薰衣草紫）
- 色彩微调在 Phase 1 实施时根据视觉效果实时决定
- 品牌色投影：按钮/卡片阴影使用 rgba 品牌色替代灰色阴影

### 2.3 聊天气泡：品牌化 + 猫耳圆角

- 用户气泡：粉色渐变背景 + 圆尾造型（无尖角）
- Bot气泡：玻璃拟态背景 + 不对称圆角 `4px 16px 16px 16px`（模拟猫耳）
- Bot 头像与 Agnes 心情状态联动

### 2.4 暗黑模式：情境化组合

- **高情感页面**（启动/聊天/首页）：深灰半透明+blur+极暗发光体（A+A）
- **功能/数据页面**（Bot管理/设置/数据面板）：纯深色+微光边框+无光斑（B+B）
- 用户可一键关闭"暗黑模式氛围光效"，全部退化为 B+B

### 2.5 聊天背景

- 保留并增强：提供预设背景集（纯色/渐变/品牌主题）
- P0 阶段先实现预设集，自定义图片留 P1

### 2.6 素材来源

- **图标**：Lucide Icons 为基础 + Tabler/Phosphor 补充猫/Bot/表情类 + 品牌专属图标在现有基础上 Figma 改路径
- **Agnes 角色**：核心8种心情表情外包画师精修，节日/场景类 AI 生成+手动调整，idle 动画用 CSS 微动
- **字体**：系统字体（零加载），标题可选免费商用字体，代码块用 JetBrains Mono（P1）
- **装饰**：全部代码化（CSS/SVG），不依赖图片资源
- **动效**：基础用 CSS，复杂动画预留 Lottie 支持

## 三、动效系统

### 3.1 分层策略

- **核心动效**（必须保留）：底部导航胶囊滑动+弹簧、聊天气泡入场、页面转场、按钮点击反馈（scale+ripple）
- **氛围动效**（中端以上设备）：导航胶囊双层拖尾blur、启动页浮动光球+飘落花瓣、卡片hover shadow、Agnes心情idle动画

### 3.2 页面转场：混合模式

- 底部 Tab 切换 → 淡入淡出（200ms）
- 进入子页面 → 右推入（translateX）
- 返回 → 左推入（反向）

### 3.3 用户控制

- 性能设置面板提供逐项动效开关（详见第六节）

## 四、Agnes 心情系统

### 4.1 驱动方式

- 混合方案：规则驱动基础心情 + AI 偶尔注入惊喜心情

### 4.2 心情集合（6基础 + 2特殊）

| 心情 | 触发条件 | 表现 |
|------|---------|------|
| 开心（默认） | 正常使用 | 微笑、眨眼、轻微摆动 |
| 想念 | 30+分钟无互动后重新打开 | 趴屏幕边缘、期待眼神、"你回来啦"气泡 |
| 兴奋 | 连续聊天10+分钟/快速发消息 | 跳跃、瞳孔放大、星星特效 |
| 困倦 | 凌晨0-6点在线 | 打哈欠、半闭眼、点头 |
| 无聊 | 停留非聊天页5+分钟 | 角落画画/玩毛线球、偷看用户 |
| 委屈 | 长时间不回复Bot消息 | 耳朵下垂、嘴巴撅起 |
| 庆祝（特殊） | 节日/生日/成就 | 专属服饰+特效（见节日系统） |
| 惊喜（AI） | LLM根据聊天内容触发 | 特殊表情/动作 |

### 4.3 节日庆祝系统

- 不同节日有专属视觉元素（服饰、特效）
- 持续时间：1天节日=1天、传统节日=3天、春节=7天、生日/注册周年=1天
- 检测方式：公历直接比对、农历用轻量库转换、用户数据从API获取

## 五、导航与架构

### 5.1 SPA 架构

- 统一 SPA 代码，核心页面（首页/聊天/我的Bot/我的/通知）合并为 SPA shell
- 低频页面（启动/登录/注册/创建向导/数据面板/管理员/设置子页）保持独立HTML

### 5.2 三档加载策略（用户可选）

- **自动**：根据设备性能推荐（默认）
- **省流量**：按需加载
- **标准**：提前加载常用页面
- **极速**：启动时加载全部页面

### 5.3 信息架构（混合）

- 管理员面板 → Tab 分页
- 数据面板 → 纵向滚动 + 渐进披露（核心数据流保持滚动，低频模块折叠）
- API Key 管理 → Tab 分页

## 十、安全规范（贯穿全阶段）

> 本节为 UI 重构必须遵守的安全底线，所有新代码必须遵守。

### 10.1 代码注入防护

| # | 规范 | 说明 |
|---|------|------|
| S1 | 禁止 innerHTML 拼接用户数据 | 必须使用 `createElement` + 安全属性赋值 |
| S2 | 全局统一 `escapeHtml()` | 已由 `app.js` 提供（覆盖 `&<>'"`），禁止本地重复定义 |
| S3 | 禁止 `eval()` / `new Function()` | 不允许动态代码执行 |
| S4 | 事件委托代替 onclick 拼接 | 动态数据通过 `data-*` 属性传递，JS 事件监听读取 |

### 10.2 Token 与认证安全

| # | 规范 | 说明 |
|---|------|------|
| S5 | JWT 客户端过期检测 | `api.js` 已实现 `_jwtExpired()`，SPA 路由守卫应复用 |
| S6 | Mock token 仅限 dev_mode | 生产代码不得包含 `dev.mock` 前缀的特殊处理 |
| S7 | 敏感接口鉴权 | 文件下载等敏感操作必须通过 `fetch + blob`（已实现），禁止 `window.open` 无鉴权 |

### 10.3 网络安全

| # | 规范 | 说明 |
|---|------|------|
| S8 | CSP 策略 | `app.js` 已注入 CSP meta，SPA 迁移后应保持 |
| S9 | URL 协议白名单 | `_resolveUrl()` 已过滤 `javascript:` / `vbscript:`，新页面必须复用 |
| S10 | WS 指数退避重连 | `api.js` 已实现（3s→30s上限），SPA 复用 |

### 10.4 SPA 新增安全要求

| # | 规范 | 说明 |
|---|------|------|
| S11 | 路由白名单 | `router.js` 必须维护合法路由列表，拒绝非法路径 |
| S12 | 视图鉴权守卫 | 需要登录的视图必须在加载前检查 token 有效性 |
| S13 | 心情数据验证 | `mood-engine.js` 从后端接收的心情数据必须校验边界，不信任远程数据 |
| S14 | 第三方库 SRI | 若引入外部 JS/CSS，必须添加 `integrity` + `crossorigin` 属性 |
| S15 | 节日配置验证 | 后端返回的节日配置必须校验字段类型和边界 |
| S16 | 图片 URL 验证 | 自定义图片背景（P1）必须验证 URL 协议为 `http(s)` 或 `data:image/` |

### 10.5 安全验收检查点

每个 Phase 完成后，需额外检查：

- [ ] 所有 `innerHTML` 赋值中的动态数据均已转义
- [ ] 无新增本地 `_esc` / `escapeHtml` / `_resolveUrl` 定义
- [ ] 无 `console.log` 输出 token / 密码 / 服务器地址
- [ ] 新增的 `<script src>` / `<link>` 均为本地文件或有 SRI
- [ ] 新增页面的 `_resolveUrl` 调用均来自 `app.js` 全局版本
